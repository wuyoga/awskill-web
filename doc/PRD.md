# awskill 产品需求文档（PRD）

> 产品：awskill（Agent Workflow Skills）
> 域名：awskill.com
> 版本：v0.1
> 状态：用于 MVP 技术设计与任务拆分
> 默认语言：简体中文
> 目标技术栈：Next.js、Strapi CMS、PostgreSQL、Meilisearch

## 1. 产品概述

awskill 是中文 AI Agent Skill 评测与发现平台，通过 Agent 兼容性、安全权限、真实任务评测和可复用工作流，帮助用户在安装前做出可解释的选择。

### 1.1 产品主张

> 不只看热度，安装前先确认兼容性、安全风险和真实任务表现。

### 1.2 MVP 目标

1. 用户能在 3 分钟内找到适合指定 Agent 和任务的 Skill。
2. 用户在详情页能明确判断是否兼容、需要什么权限、结论是否新鲜。
3. 用户能复制针对目标 Agent 的正确安装命令。
4. 用户能比较候选项，并查看真实任务评测依据。
5. 编辑团队能通过 CMS 完成录入、审核、发布、下架和重新验证管理。

### 1.3 非目标

- MVP 不提供 Skill 在线执行或托管运行环境。
- MVP 不建立独立 MCP 目录。
- MVP 不开放用户评分来替代专业评测。
- MVP 不承诺支持四个 Agent 之外的安装方案。
- MVP 不以单一综合分对 Skill 排名。
- MVP 不实现付费交易或 Skill 市场分成。

## 4. 功能需求

### 4.1 首页

#### FR-HOME-01 全局搜索

- 支持输入 Skill 名称、作者、仓库、标签或自然语言任务。
- 回车或点击搜索后进入 Skill 发现页，并保留查询词。
- 支持 `Ctrl/Cmd + K` 聚焦搜索框。

**验收标准**

- 中文和英文关键词均可召回对应内容。
- 查询词出现在 URL 中，可分享、刷新和前进后退。
- 无输入时进入全部 Skill 列表。

#### FR-HOME-02 核心信任信息

- 展示首批支持的四个 Agent。
- 展示经过任务实测的精选 Skill。
- 展示 10 个任务分类。
- 展示兼容性、安全和真实评测的价值说明。
- 所有统计数字必须来自真实数据源，不得硬编码演示数量。

### 4.2 Skill 搜索与筛选

#### FR-SEARCH-01 搜索

- Meilisearch 提供全文搜索、拼写容错和中英文关键词召回。
- 搜索字段至少包含名称、描述、标签、关键词、作者、仓库和分类。
- 无结果时提供清除筛选和浏览分类的入口。

#### FR-SEARCH-02 Facet 筛选

支持：

- 10 个一级分类，单选。
- Agent，单选；只有兼容状态不是“未验证”的 Skill 才命中。
- 验证状态，多选。
- 安全等级，多选。
- 使用要求，多选且为 AND 关系。
- 输出格式，多选且为 OR 关系。

**验收标准**

- 所有条件写入 URL。
- 刷新和分享 URL 后结果一致。
- 分类旁数量随其他筛选条件动态变化。
- 桌面端使用侧栏，移动端使用底部抽屉。
- 抽屉关闭后页面不残留滚动锁定。

#### FR-SEARCH-03 排序

提供：

- 综合推荐：先验证状态、再风险状态、再使用量。
- 最近验证。
- 最多使用。
- 最新收录。

综合推荐的具体权重应可配置并形成文档，不能由前端隐式决定。

### 4.3 Skill 详情

#### FR-SKILL-01 基础信息

展示名称、作者、来源仓库、说明、分类、标签、许可证、前置条件、输出格式、收录时间、来源更新时间和可验证的热度信息。

#### FR-SKILL-02 Agent 兼容性

为 Claude Code、Codex、Cursor、Windsurf 分别展示：

- 完整支持、部分支持或未验证。
- Agent 版本、操作系统、验证时间。
- 部分支持原因。
- 验证 Commit。

如果来源最新 Commit 不同于验证 Commit，必须突出显示结论可能过期。

#### FR-SKILL-03 安全与权限

展示风险等级、风险摘要和以下权限：

- 读取项目文件。
- 修改项目文件。
- 执行 Shell。
- 访问网络。
- 访问系统凭据。
- 删除文件。

每个权限包含“需要、有限、未发现、待评估”状态及原因。不得只展示风险颜色而不展示解释。

#### FR-SKILL-04 分 Agent 安装

用户选择 Agent 后，展示：

- 安装命令。
- 卸载命令。
- 目标目录。
- 文件格式或转换说明。
- 兼容性警告。
- 一键复制。

安装方案固定采用方案 B：不同 Agent 使用不同命令和说明。

#### FR-SKILL-05 使用建议

展示适用场景、不适用场景、示例 `SKILL.md` 或核心说明，以及关联评测和工作流。

#### FR-SKILL-06 MCP 关系

增加“依赖或搭配的 MCP”栏目：

- MCP 名称及官网/仓库。
- 关系类型：必需、可选增强。
- 用途说明。
- 配置前置条件。

MVP 不提供独立 MCP 目录和 MCP 全站导航。

#### FR-SKILL-07 收藏

- 匿名用户可收藏，数据保存在本地。
- 收藏按钮即时反馈。
- 登录后可将本地收藏合并到账户。
- 同一 Skill 合并后不得重复。

### 4.4 Skill 对比

#### FR-COMPARE-01 候选管理

- 最少 2 个、最多 3 个 Skill。
- 可从卡片加入/移出。
- 对比页可替换和删除候选。
- 对比列表保存在 URL，便于分享。

#### FR-COMPARE-02 对比维度

至少包含：

- 验证状态和最近验证时间。
- 四个 Agent 的兼容状态。
- 安全等级与主要权限。
- API Key、付费、网络和 Shell 要求。
- 输出格式、许可证和安装情况。
- 关联任务评测结论。

移动端允许横向滚动，首列维度名称保持可识别。

### 4.5 评测

#### FR-REVIEW-01 评测方法

正式评测遵循：

1. 同类 Skill 使用相同任务、输入和验收标准。
2. 使用隔离环境。
3. 记录 Agent、版本、模型、系统和 Commit。
4. 保存结果、耗时、人工干预和命令记录。
5. 付费或合作不能改变测试和安全结论。

#### FR-REVIEW-02 评测详情

展示：

- 固定任务和验收标准。
- 参与 Skill 或无 Skill 基线。
- 完整环境。
- 分维度结果，不生成总分。
- 是否完成、耗时、人工干预次数、结论与说明。
- 证据清单和经过脱敏的证据文件。

#### FR-REVIEW-03 结论

Skill 的评测结论可为推荐、有条件推荐、不推荐。结论必须绑定具体 Agent、版本和 Commit，不可脱离环境作为永久判断。

### 4.6 工作流

#### FR-WORKFLOW-01 工作流内容

工作流包括标题、目标、分类、难度、预计时间、步骤和整体已验证 Agent。每一步必须关联一个 Skill，并说明目标、输入和输出。

#### FR-WORKFLOW-02 组合风险

组合风险取步骤中最高风险等级，并列出全部关键权限。若某个 Skill 对所选 Agent 未验证，必须显示警告。

#### FR-WORKFLOW-03 批量安装

用户选择 Agent 后，按步骤生成对应安装命令。命令可一次复制，但界面仍需逐项展示，以便用户理解每个依赖。

“整体验证”只表示该工作流在指定 Agent 上完成过端到端测试，不能由各步骤单独兼容自动推导。

### 4.7 Agent 页面

#### FR-AGENT-01 Agent 概览

展示四个 Agent 的特点、原生格式、安装目录、已验证数量和兼容数量。

#### FR-AGENT-02 Agent 详情

展示：

- 安装约定和格式转换。
- 完整支持、部分支持的解释。
- 最近验证 Skill。
- 推荐工作流。
- 已知限制。

统计数据必须动态计算。

### 4.8 登录、账户与提醒

#### FR-AUTH-01 GitHub 登录

- 首选 GitHub OAuth。
- 登录失败后保留原访问页面。
- 不要求登录才能浏览、搜索、复制命令或本地收藏。

#### FR-AUTH-02 收藏同步

- 登录后同步跨设备收藏。
- 首次登录时合并本地和服务端收藏。
- 删除操作使用明确的最后写入策略，并记录更新时间。

#### FR-NOTIFY-01 提醒

登录用户可分别订阅：

- Skill 来源更新。
- 兼容性重新验证。
- 安全等级变化。
- 新评测发布。

MVP 可先实现站内提醒；邮件提醒需在渠道和退订规则确认后上线。

### 4.9 Skill 提交与审核

#### FR-SUBMIT-01 投稿

投稿至少包含仓库 URL、Skill 路径、名称、说明、支持 Agent 声明和提交者备注。

#### FR-SUBMIT-02 审核状态

状态包括待初审、待补充、待安全评估、待兼容验证、可发布、已拒绝、已发布、已下架。

公开页面不得直接展示未经审核的提交内容。

## 5. 内容与数据模型

以下为逻辑模型；字段类型、组件拆分和关系由 Strapi 技术设计进一步细化。

### 5.1 Skill

- `name`、`slug`、`owner`、`repositoryUrl`、`repositoryPath`
- 本地化 `title`、`description`、`keywords`、`useCases`、`notFor`
- `category`、`tags`、`outputs`
- `license`、`prerequisites`
- `needsApiKey`、`isPaid`
- `sourceLatestCommit`、`sourceUpdatedAt`、`syncedAt`
- `verificationStatus`
- `riskLevel`、本地化 `riskSummary`
- `publishedAt`、`archivedAt`

### 5.2 Agent

- `name`、`slug`、`status`
- 本地化 `description`
- `installDirectoryTemplate`
- `installCommandTemplate`
- `uninstallCommandTemplate`
- `nativeFormat`、`conversionNotes`

安装模板应由受控配置生成，编辑者不能写入任意可执行脚本而绕过审核。

### 5.3 CompatibilityVerification

- `skill`、`agent`
- `compatibilityStatus`
- `agentVersion`、`model`、`os`
- `verifiedCommit`、`verifiedAt`
- 本地化 `notes`
- `reviewer`、`evidence`

同一 Skill 和 Agent 可保留历史记录，公开页默认展示最新有效记录。

### 5.4 PermissionAssessment

- `skill`
- `permissionType`
- `level`
- 本地化 `reason`
- `source`：自动扫描、人工复核或两者
- `assessedCommit`、`assessedAt`、`reviewer`

### 5.5 Review

- 本地化标题、摘要、任务、验收标准
- 分类、参与 Skill、是否包含基线
- Agent、版本、模型、操作系统、测试 Commit
- 评测维度及每个参与者结果
- 每次运行的完成状态、耗时、干预次数、结论和说明
- 证据媒体、脱敏状态、公开级别
- 作者、审核者、发布日期

### 5.6 Workflow

- 本地化标题、摘要
- 分类、难度、预计时间
- 有序步骤：Skill、目标、输入、输出
- 整体验证 Agent 与验证记录
- 发布状态

### 5.7 MCP

- 名称、slug、官网/仓库、本地化说明
- 与 Skill 的关系：必需或可选增强
- 配置说明和环境变量名称

仅作为 Skill 详情关联内容，不提供独立目录。

### 5.8 UserFavorite 与 NotificationPreference

- 收藏：用户、Skill、创建和更新时间。
- 提醒偏好：用户、Skill、事件类型、渠道、启用状态。
- 匿名收藏继续存储在客户端，登录时调用合并接口。

## 6. 搜索需求

### 6.1 Meilisearch 索引

索引名建议按环境和版本区分，例如 `production_skills_v1`。

可搜索字段：

- 中英文名称、描述、标签、关键词。
- 作者、仓库、分类。

可筛选字段：

- `category`
- `agents`
- `verificationStatus`
- `riskLevel`
- `needsApiKey`
- `isPaid`
- `needsShell`
- `needsNetwork`
- `outputs`
- `isPublished`

可排序字段：

- `lastVerifiedAt`
- `installCount`
- `publishedAt`
- 经过文档化的 `recommendationRank`

### 6.2 同步

- Strapi 发布、更新、下架后触发增量更新。
- 每日执行 PostgreSQL 与 Meilisearch 一致性校验。
- 索引失败不得阻断内容保存，但必须进入重试队列和后台告警。
- 搜索结果只包含已发布且未下架内容。

## 7. API 与系统边界

### 7.1 公开读取

Next.js 服务端读取 Strapi API；浏览器不直接持有 Strapi 管理权限。公开 API 仅返回已发布字段和公开证据。

### 7.2 用户写入

收藏、提醒和投稿必须经过认证、限流和字段校验。所有用户生成内容默认进入审核状态。

### 7.3 后台任务

- GitHub 仓库元数据与 Commit 同步。
- 结论过期检测。
- Meilisearch 索引更新。
- 通知生成和发送。
- 失败重试与审计日志。

## 8. 非功能需求

### NFR-01 性能

- 公开页面优先使用服务端渲染或静态生成。
- 核心 Web Vitals 在常见移动设备上达到“良好”目标。
- 搜索交互在索引服务正常时应在 500 ms 内反馈首屏结果。
- 图片和评测证据使用响应式尺寸与延迟加载。

### NFR-02 SEO

- 使用可读路径，不使用 hash 路由。
- Skill、评测、工作流和 Agent 页面具有独立 title、description、canonical 和 Open Graph。
- 生成 sitemap 和 robots 配置。
- 中英文页面使用正确 `hreflang`。
- 下架内容根据原因返回 404 或保留带说明的归档页。

### NFR-03 可访问性

- 键盘可完成搜索、筛选、切换 Agent、收藏和复制。
- 焦点状态清晰，抽屉具备焦点管理。
- 颜色不是状态的唯一表达方式。
- 主要页面按 WCAG 2.2 AA 检查。

### NFR-04 安全

- OAuth 使用安全回调和 CSRF 防护。
- 管理端启用最小权限角色。
- 富文本和用户提交内容进行清洗。
- 评测证据上传限制类型、大小，并执行敏感信息检查。
- 安装命令由受控模板生成并经过审核。
- 记录内容发布、安全结论变更和下架审计日志。
- 密钥仅保存在服务端环境变量中。

### NFR-05 隐私

- 匿名收藏仅保存在本地。
- 登录、提醒和分析事件遵循隐私政策。
- 提供账户数据导出和删除方案。
- 分析工具不得采集 Skill 安装命令中的私人参数。

### NFR-06 国际化

- 中文为默认语言。
- URL、元数据、正文和枚举标签均支持本地化。
- 内容未翻译时必须有明确回退规则，后台可检查翻译完整度。

### NFR-07 可观测性

- 记录前端错误、API 错误、搜索失败、索引同步失败和后台任务失败。
- 核心链路使用请求 ID 关联日志。
- 不在日志记录 OAuth Token、密钥或未经脱敏的证据内容。

## 9. 分析与指标

### 9.1 核心漏斗

1. 进入首页或落地页。
2. 搜索或选择分类。
3. 打开 Skill 详情。
4. 切换目标 Agent。
5. 复制安装命令。

### 9.2 关键指标

- 搜索后详情打开率。
- 无结果搜索率。
- 详情页安装命令复制率。
- 兼容性和安全区域展开/浏览率。
- 对比创建率和完成率。
- 匿名收藏率、登录后收藏同步率。
- 评测阅读完成度。
- 工作流到各 Skill 详情的转化。
- MCP 关联栏点击率，用于判断是否建立 MCP 专区。

分析事件不得包含用户输入的完整敏感查询；必要时采用脱敏或聚合。

## 11. MVP 总体验收

MVP 可发布必须同时满足：

1. 四个首批 Agent 均有明确安装约定和兼容状态说明。
2. 10 个分类和全部独立筛选维度可用，且 URL 可复现结果。
3. 每个公开 Skill 至少包含来源、分类、一个 Agent 兼容记录、安全评估和安装说明。
4. 所有“任务已实测”内容都绑定环境、Commit、验收标准和证据。
5. 来源更新后，旧结论能够自动显示过期状态。
6. 匿名收藏可用；账户功能未上线时不阻碍核心浏览和安装。
7. 不存在将演示数量或演示结论伪装成真实数据的页面。
8. 搜索、详情、复制安装命令、对比在桌面和移动端均可完成。
9. CMS 权限、用户写接口、证据上传和安装模板通过安全检查。
10. 关键页面具有正确中文 SEO 元数据，并满足基本性能和可访问性要求。

## 12. 发布后候选项

以下内容不纳入当前 MVP 承诺，需由数据验证后另立 PRD：

- 独立 MCP 目录。
- 更多 Agent。
- 用户评论和社区评分。
- 自动安装客户端或浏览器扩展。
- 团队收藏夹和组织级策略。
- Skill 版本差异比较。
- 评测环境的自动化编排平台。
- 面向 Skill 作者的流量、兼容性和质量分析面板。
